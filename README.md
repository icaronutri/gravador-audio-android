# Gravador Áudio Android

Projeto Android do Transcritor IA, criado para evoluir a extensão de áudio para um aplicativo Android independente.

## Objetivo inicial

- Gravar áudio pelo microfone
- Pausar e retomar
- Exibir cronômetro
- Continuar funcionando minimizado
- Transcrever em português
- Salvar áudio e transcrição no histórico
- Permitir abrir, copiar e compartilhar transcrições

Este repositório será usado para gerar e testar o APK do aplicativo.
